# wc-2026

wc-2026 is a community-driven, non-profit educational project that provides example code, sample assets, and short lessons to help learners and educators explore modern web development, design, and accessibility best practices. Media included here is intended for learning and demonstration; please respect third-party copyrights and licenses when contributing or reusing assets.

Highlights

- Educational sample apps and components (see src/)
- Sample media and assets for prototyping (see public/assets/)
- Emphasis on accessibility, responsible media use, and clear examples

Quick start

1. Clone the repo
2. npm install
3. npm run dev
